Este projeto é um sistema web desenvolvido para otimizar e automatizar a rotina de revendedores independentes de O Boticário. Criado como parte da disciplina de Projeto Integrador II do 2º semestre do curso de Análise e Desenvolvimento de Sistemas (Senac Santo Amaro), a aplicação centraliza o controle das operações comerciais e melhora a experiência e interação com os consumidores finais.

## 🎯 Funcionalidades Principais

O sistema foi arquitetado com dois módulos de acesso distintos para separar a gestão de negócios da experiência de compra:

### 📦 Área do Revendedor
* **Controle de Estoque:** Monitoramento em tempo real dos produtos disponíveis, com registro de entradas e saídas.
* **Gestão Financeira:** Acompanhamento de lucros, despesas, repasses e fluxo de caixa geral.
* **Registro de Vendas:** Histórico detalhado de transações, clientes atendidos e pedidos finalizados.

### 🛍️ Área do Cliente
* **Portal de Acesso:** Interface dedicada para que os clientes do revendedor possam visualizar os produtos em estoque, fazer pedidos e acompanhar o status de suas compras de forma independente.

## 💻 Tecnologias Utilizadas

A interface da aplicação está sendo construída utilizando o framework **Angular**, com as seguintes proporções de linguagens mapeadas no repositório[cite: 2]:
* **CSS (42.6%)**[cite: 2]: Estilização visual, desenhada para se alinhar à identidade da marca O Boticário.
* **HTML (33.7%)**[cite: 2]: Estruturação semântica de componentes e páginas.
* **TypeScript (23.7%)**[cite: 2]: Lógica de programação, rotas e integração de dados nos componentes do Angular.
